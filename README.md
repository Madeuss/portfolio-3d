# Madeus 3D

Portfólio 3D jogável do Mateus Souza: a "casa dos sonhos", onde você anda com um mini-Mat e abre projetos, experiências e contato interagindo com os objetos.

No ar em **[3d.madeusdev.com](https://3d.madeusdev.com)** (Cloudflare Workers, deploy a cada push na `main`).

Stack: Vite, React, TypeScript, three.js com React Three Fiber e drei.

```bash
yarn        # instala
yarn dev    # servidor local
yarn build  # build de produção
```

## Créditos

Avatar e móveis: gerados com IA (imagens no Gemini, modelos e rig no [Tripo](https://www.tripo3d.ai/)). Animações extras do [Mixamo](https://www.mixamo.com/).

Assets provisórios (CC0, domínio público, salvo onde indicado):

- Sons: [Impact Sounds](https://kenney.nl/assets/impact-sounds), [Interface Sounds](https://kenney.nl/assets/interface-sounds), [RPG Audio](https://kenney.nl/assets/rpg-audio) (porta) e [Music Jingles](https://kenney.nl/assets/music-jingles) (gol), Kenney
- Cachorro: [Cartoon Dog](https://sketchfab.com/3d-models/cartoon-dog-d4e8e37ea031422b843dc09587d21260), assetfactory (Sketchfab, licença Standard, não é CC0); provisório até o modelo próprio
- Céu (HDRI): [Kloofendal 48d Partly Cloudy (Pure Sky)](https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky), Poly Haven
